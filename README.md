# Cloud Computing Resources

A curated collection of **cloud computing learning materials and resources** — including diagrams, notes, AWS summaries, Kubernetes examples, and useful commands.

This repository is ideal for learners and aspiring cloud engineers who want a centralized place to study cloud concepts and practice with real files.

---

## 📌 Contents

Here's what you’ll find inside this repository:

### 📁 Folders
- **aws_images/** – Diagrams and AWS related visuals
- **docker/** – Docker assets and examples
- **kubernetes(k8s)/** – Kubernetes resources and configurations

### 📄 Key Files
- **Cloud_Computing Notes.pdf** – Comprehensive notes on cloud computing basics  
- **IP_Address_and_Subnetting_NetworkChuck_Summary.txt** – Summary of subnetting concepts  
- **iaas-paas-saas-diagram.png** – Visual overview of Cloud service models (IaaS / PaaS / SaaS)  
- **Various network and CLI summaries** – Useful command snippets and networking insights

---

## 🚀 Features

- 🧠 Concept diagrams to help visual learners  
- 📘 Text summaries and notes to reinforce theory  
- 🛠️ Sample tech files (Kubernetes, Docker) for hands-on practice  
- 📚 Useful walkthrough files on networking and cloud basics

---

## 🧰 How to Use This Repo

1. **Browse the files** to explore specific cloud topics.
2. Open **PDFs and diagrams** to study architectural and high-level concepts.
3. Use **text summaries** to revise key ideas or commands.
4. Explore the *docker* and *kubernetes* folders to try real configurations and setups.
